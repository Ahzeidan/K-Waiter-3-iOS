# سياسة خصوصية K-Waiter

السياسة النهائية ثنائية اللغة موجودة داخل Laravel في:

`resources/views/legal/k-waiter-privacy.blade.php`

بعد رفع حزمة السيرفر تصبح متاحة على:

```text
https://YOUR-DOMAIN/api/waiter/v3/privacy
```

وللسيرفر الحالي يكون الرابط المتوقع:

```text
https://res.kemetkw.com/api/waiter/v3/privacy
```

تاريخ السريان: 15 أغسطس 2026. يجب تحديث النص إذا أُضيفت تحليلات، إعلانات، تتبع موقع، بوابة دفع تجمع بيانات بطاقة داخل التطبيق، أو أي SDK يجمع بيانات جديدة.
